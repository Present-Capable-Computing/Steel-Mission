# Steel Mission Portfolio

Steel Mission manages delivery as stable projects with explicit outcomes, boundaries, milestones, risks, and completion evidence. A project organizes work; it does not grant authority and it does not turn schedule state into proof that the work is correct.

The portfolio begins with `PRJ-0001`, Durable Core. It has six epics and 58 GitHub issues in total: six epic issues and 52 child delivery issues. More projects are expected, but none receives an identifier or implied scope before its project record is adopted.

Project and milestone records are the durable source of truth. GitHub issues and the Projects board are working surfaces projected from those records. Verification remains in task contracts, verification records, and the evidence chain.
